# Гид по Нижнему Новгороду

Веб-приложение — туристический путеводитель по Нижнему Новгороду. Позволяет просматривать достопримечательности, готовые пешеходные маршруты, добавлять их в избранное, а также самостоятельно планировать маршруты с помощью Яндекс Карт.

## Технологии

### Клиент

| Технология | Назначение |
|---|---|
| React 19 | UI-фреймворк |
| TypeScript | Типизация |
| Vite 7 | Сборка и dev-сервер |
| Axios | HTTP-клиент |
| Yandex Maps API | Интерактивные карты |

### Сервер

| Технология | Назначение |
|---|---|
| Node.js + Express 5 | REST API |
| Sequelize 6 | ORM для PostgreSQL |
| PostgreSQL | База данных |
| JSON Web Token | Аутентификация |
| bcrypt | Хэширование паролей |
| Multer | Загрузка файлов |
| Swagger UI | Документация API |

## Требования

- **Node.js** >= 18
- **npm** >= 9
- **PostgreSQL** >= 14
- Ключи API Яндекс Карт (JavaScript API и Router API)

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <url-репозитория>
cd nizhny-travel
```

### 2. Установка зависимостей

```bash
npm install
npm install --prefix client
npm install --prefix server
```

### 3. Настройка переменных окружения

Скопируйте шаблон и заполните значения:

```bash
cp server/.env.local server/.env
```

### 4. Создание базы данных

```bash
createdb nizhny_travel
```

### 5. Применение миграций и заполнение данными

```bash
cd server
npx sequelize-cli db:migrate
npx sequelize-cli db:seed:all
cd ..
```

### 6. Запуск в режиме разработки

Из корня проекта (запускает клиент и сервер одновременно):

```bash
npm run dev
```

- Клиент: http://localhost:5173
- Сервер: http://localhost:5000
- Swagger: http://localhost:5000/api-docs

## Модули приложения

### Достопримечательности

Каталог мест с фотографиями, описаниями и расположением на карте. Поддерживается поиск по названию, фильтрация по категориям (музеи, парки, храмы, площади и др.) и тегам (историческое, панорамный вид, бесплатно и др.).

### Маршруты

Готовые пешеходные маршруты с указанием продолжительности, расстояния и списком достопримечательностей. Маршруты отображаются на карте с точками и полилинией пути.

### Планировщик маршрутов

Интерактивный инструмент для создания собственных маршрутов. Пользователь выбирает точки на карте, система строит пешеходный маршрут через Yandex Router API (до 25 точек, с возможностью оптимизации порядка). Готовый маршрут можно сохранить в личном кабинете.

### Карта

Обзорная карта всех достопримечательностей с маркерами. При клике на маркер открывается карточка места.

### Авторизация и личный кабинет

Регистрация и вход по email и паролю. В личном кабинете — редактирование профиля (имя, телефон, аватар), просмотр избранных мест и маршрутов, управление сохранёнными маршрутами из планировщика.

### Избранное

Авторизованные пользователи могут добавлять места и маршруты в избранное. Избранное отображается как в каталоге (иконка на карточке), так и в личном кабинете.

## Схема базы данных

### Основные таблицы

**users** — пользователи
| Столбец | Тип | Описание |
|---|---|---|
| id | INTEGER PK | Идентификатор |
| email | TEXT UNIQUE | Электронная почта |
| password | TEXT | Хэш пароля |
| role_id | INTEGER FK → roles | Роль |
| username | TEXT UNIQUE | Логин |
| name | TEXT | Имя |
| phone | TEXT | Телефон |
| avatar_url | TEXT | URL аватара |

**roles** — роли (admin, user)
| Столбец | Тип | Описание |
|---|---|---|
| id | INTEGER PK | Идентификатор |
| name | TEXT | Название роли |

**places** — достопримечательности
| Столбец | Тип | Описание |
|---|---|---|
| id | INTEGER PK | Идентификатор |
| name | TEXT | Название |
| description | TEXT | Описание |
| category_id | INTEGER FK → categories | Категория |
| address | TEXT | Адрес |
| latitude | DECIMAL | Широта |
| longitude | DECIMAL | Долгота |
| main_photo | TEXT | URL главного фото |

**categories** — категории мест (музеи, парки, храмы и др.)
| Столбец | Тип | Описание |
|---|---|---|
| id | INTEGER PK | Идентификатор |
| name | TEXT | Название |
| image | TEXT | URL иконки |

**tags** — теги мест (историческое, бесплатно и др.)
| Столбец | Тип | Описание |
|---|---|---|
| id | INTEGER PK | Идентификатор |
| name | TEXT | Название |

**routes** — готовые маршруты
| Столбец | Тип | Описание |
|---|---|---|
| id | INTEGER PK | Идентификатор |
| name | VARCHAR(255) | Название |
| description | TEXT | Описание |
| main_photo | TEXT | URL фото |
| duration_minutes | NUMERIC | Длительность (мин.) |
| distance_km | NUMERIC | Расстояние (км) |

**places_photos** — галерея фотографий места
| Столбец | Тип | Описание |
|---|---|---|
| id | INTEGER PK | Идентификатор |
| place_id | INTEGER FK → places | Место |
| photo | TEXT | URL фото |
| order | INTEGER | Порядок отображения |

### Связующие таблицы

**routes_places** — места в маршруте
| Столбец | Тип | Описание |
|---|---|---|
| route_id | INTEGER FK → routes | Маршрут |
| place_id | INTEGER FK → places | Место |
| order_index | INTEGER | Порядок в маршруте |

**tags_places** — теги мест
| Столбец | Тип | Описание |
|---|---|---|
| tag_id | INTEGER FK → tags | Тег |
| place_id | INTEGER FK → places | Место |

**favourite_places** — избранные места пользователя
| Столбец | Тип | Описание |
|---|---|---|
| user_id | INTEGER FK → users | Пользователь |
| place_id | INTEGER FK → places | Место |

**favourite_routes** — избранные маршруты пользователя
| Столбец | Тип | Описание |
|---|---|---|
| user_id | INTEGER FK → users | Пользователь |
| route_id | INTEGER FK → routes | Маршрут |

### Таблицы планировщика

**saved_routes** — сохранённые пользовательские маршруты
| Столбец | Тип | Описание |
|---|---|---|
| id | INTEGER PK | Идентификатор |
| user_id | INTEGER FK → users | Пользователь |
| name | VARCHAR(255) | Название маршрута |
| distance_km | NUMERIC | Расстояние (км) |
| duration_minutes | INTEGER | Длительность (мин.) |
| route_geometry | JSONB | Геометрия маршрута (полилиния) |
| start_place_id | INTEGER FK → places | Начальная точка |

**saved_route_places** — точки в сохранённом маршруте
| Столбец | Тип | Описание |
|---|---|---|
| saved_route_id | INTEGER FK → saved_routes | Маршрут |
| place_id | INTEGER FK → places | Место |
| order_index | INTEGER | Порядок |
| leg_duration_minutes | INTEGER | Время до следующей точки (мин.) |
| leg_distance_km | NUMERIC | Расстояние до следующей точки (км) |
